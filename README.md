# ボートレース 予想・買い目の作成

受領した統合版の抽出・買い目ルールを使い、送付された表の26区分と列順を保持する、スマートフォン向けの作成画面です。元のアーカイブは変更していません。

## 使い方

1. 開催日を確認して「公式情報を取得して一覧を作成」を押します。公式開催一覧を読み、各開催場の公式出走表へのリンクを確認してから取得します。
2. 取得件数と未取得・中止の表示、出走6艇、買い目を確認します。公式サイトの中止・順延は取得時点の情報であり、出走取消・選手変更や取得後の変更は自動追跡しないため、利用前に公式出走表を確認してください。
3. 必要に応じてCの画像を添付し、端末内で読み取った候補を画像と照合して指定します。OCR候補をそのまま確定することはありません。
4. 「集計用データを保存（JSON）」で全レース入力、抽出結果、指定、26区分、取得状況を保存できます。「読みやすいテキストを保存」は表の内容をタブ区切りの文章にします。いずれも予想の真正性や作成時刻を証明するものではありません。画像本体は含みません。

A仮説は10点、B仮説は8点、C仮説は16点です。新規作成内容は未照合として扱います。結果の自動入力・集計解析や舟券購入は含みません。保存した画像本体を含む端末内履歴は、別途バックアップしてください。

公式サイトでは大量アクセスなど、運営に支障を与える行為を禁止しています。自動取得はボタン操作時だけ行い、必要な場を順番に取得します。共有・再配布の際は公式サイトの利用条件を確認してください。

## 開発用

- アプリ画面: `public/creator/`
- 開催状況・出走表の取得: `app/api/` と `lib/boatrace.ts`
- ローカル検証: `node scripts/local-preview.mjs`
- 実PDFによる検証: `node tests/creation.test.mjs`（元アーカイブの検証用PDFを読み取り専用で参照）
- 本番向けビルド: サイト作成用のビルド手順を使用

ブラウザー内の保存領域は端末・ブラウザー・配信先ごとに分かれます。旧アプリの履歴は自動移行されません。実機での Android / iOS の検証は別途必要です。
